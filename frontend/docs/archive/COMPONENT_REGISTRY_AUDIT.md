### Command Palette Access (⌘K)
Users can now search for and add any of these 276+ technologies:

1. **Press ⌘K** to open Command Palette
2. **Search** for technology name (e.g., "Next.js", "PostgreSQL", "AWS EKS")

4. **Toggle icons** - labels now remain visible regardless of icon state (as per user requirement)
